## 🌟 Visão Geral

O **Blog_Aros** visa transformar conhecimento em estratégia visual para marcas e negócios. Através de uma interface moderna e intuitiva, o portal disponibiliza conteúdos atualizados sobre o ecossistema criativo, de pequenas e médias empresas a freelancers e grandes agências.

---

## 🚀 Funcionalidades e Destaques

- **Hero Video & Banner Interativo:** Seção principal de destaque com background em vídeo responsivo e chamadas diretas para leitura e newsletter.
- **Barra de Destaques Dinâmica (Marquee):** Letreiro informativo com atualizações em tempo real sobre tendências e notícias urgentes.
- **Busca de Artigos:** Sistema de busca integrado para localização rápida de conteúdos por palavra-chave.
- **Menu Navegável & Drawer Mobile:** Navegação por categorias com suporte a dropdowns no desktop e menu lateral adaptado para dispositivos móveis.
- **Feed de Notícias e Leitura:** Organização dos artigos por categorias, tempo de leitura e relevância.
- **Captação de Leads / Newsletter:** Formulário dedicado para inscrição e recebimento de atualizações por e-mail.
- **Links Sociais:** Integração completa para compartilhamento no Instagram, YouTube, LinkedIn, X (Twitter) e WhatsApp.

## 💻 Tecnologias Utilizadas

- **HTML5 Semântico:** Uso de tags adequadas (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`) para otimização SEO e leitura por leitores de tela.
- **CSS3 Moderno:** Layouts responsivos construídos com Flexbox, CSS Grid e tipografia otimizada via Google Fonts.
- **JavaScript (ES6+):** Manipulação DOM para busca de artigos, controle do menu mobile e animações interativas.
- **Netlify:** Hospedagem contínua e distribuição via CDN global.

## 🔧 Como Executar Localmente

### Pré-requisitos
Para visualizar e testar o projeto na sua máquina local, você precisará apenas de um navegador web atualizado e, opcionalmente, um servidor local simples (como a extensão *Live Server* do VS Code).

### Passos

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/blog-aros.git
   ```

2. **Navegue até a pasta do projeto:**
   ```bash
   cd blog-aros
   ```

3. **Abra o arquivo principal:**
   - Dobre o clique no arquivo `index.html` ou abra-o pelo seu navegador preferido.
   - Ou utilize o **Live Server** no Visual Studio Code para rodar com *Hot Reload*:
     ```bash
     npx serve .
     ```

## ♿ Acessibilidade & Boas Práticas

O projeto foi construído respeitando os padrões de acessibilidade **WCAG**:
- Atributos `aria-label`, `aria-haspopup`, `aria-hidden` e papeis `role="menubar"`, `role="menuitem"` e `role="search"`.
- Suporte a navegação por teclado (`Skip to main content` / `Pular para o conteúdo principal`).
- Alto contraste de texto e elementos interativos bem identificados.
- Tags de imagem com atributo `alt` descritivo.
